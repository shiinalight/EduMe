The interface works without a key. Recognizing your own photos or handwriting requires Gemini.
  1. Install Node.js 22 or newer.
  2. Copy .env.example to .env.
  3. Set GEMINI_API_KEY on the server.
  4. Run npm start and open localhost:3000.
